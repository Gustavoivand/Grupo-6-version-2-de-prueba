\section{Términos de Dominio}

\subsection{A}

\textbf{API (Application Programming Interface):}
Interfaz de programación de aplicaciones que \futureSection{permitirá} que diferentes componentes de software se comuniquen entre sí.

\textbf{Arquitectura C4:}
Modelo de documentación de arquitectura de software en 4 niveles.

\subsection{E}

\textbf{Embedding:}
Representación vectorial densa de texto que captura significado semántico.

\subsection{J}

\textbf{JWT (JSON Web Token):}
Estándar abierto para transmitir información de forma segura.
